# InsightGPT Lite

## Overview
InsightGPT Lite is an AI-Powered Data Analytics and Retrieval-Augmented Query Platform developed using Python and Streamlit.

The project combines:
- Data Analytics
- Interactive Visualization
- AI-Powered Querying
- Retrieval-Augmented Generation (RAG)
- Vector Database Search

This project is being developed as an internship and academic project for BCA Data Science specialization.

---

## Features
- CSV Dataset Upload
- Data Cleaning & Preprocessing
- Interactive Dashboard
- AI-Based Data Insights
- Natural Language Querying
- RAG-based Retrieval System
- PDF Report Generation

---

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- Scikit-learn
- LangChain
- ChromaDB
- Google Gemini AI
- Sentence Transformers
