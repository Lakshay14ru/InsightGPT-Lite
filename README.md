# 📊 InsightGPT Lite

## An AI-Powered Data Analytics and Retrieval-Augmented Query Platform

InsightGPT Lite is an AI-powered data analytics platform that allows users to upload datasets, perform preprocessing, generate visualizations, and ask natural language questions about their data using Generative AI and Retrieval-Augmented Generation (RAG).

The platform combines Data Analytics, Semantic Search, Vector Databases, and Large Language Models to provide intelligent insights from structured datasets.

# ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Lakshay14ru/InsightGPT-Lite.git
```

### Move into Project Directory

```bash
cd InsightGPT_Lite
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
