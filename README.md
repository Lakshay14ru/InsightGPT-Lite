# 📊 InsightGPT Lite

An AI-Powered Data Analytics and Retrieval-Augmented Generation (RAG) Platform built using Streamlit, Python, and Data Science technologies.

---

## 🚀 Features

✅ CSV Dataset Upload  
✅ Dataset Preview  
✅ Dataset Information Panel  
✅ Missing Value Detection  
✅ Duplicate Removal  
✅ Interactive Histograms  
✅ Scatter Plot Visualizations  
✅ Modular Utility Architecture  
✅ Streamlit Analytics Dashboard
